# Claude Code 实战（Claude Code in Action）

- **原课程**：Claude Academy《Claude Code in Action》
- **原文**：[academy.claude.com/courses/claude-code-in-action](https://academy.claude.com/courses/claude-code-in-action)
- **时长**：约 1 小时（9 课＋1 个测验）
- **适合谁**：已经用 Claude Code 处理单个提示词、想转向更长会话与团队工作流的开发者
- **状态**：🚧 翻译中（第 1 课已完成）

## 你将学到

- **驾驭工作**：用计划模式界定工作范围，定向压缩让摘要保留关键信息，用回退菜单纠偏，并在亲手把控与自主运行之间做选择
- **配置 Claude**：写一份 Claude 真正照做的精简 CLAUDE.md，把重复流程打包成技能，为每项工作选对权限模式，用钩子强制执行不可跳过的规则
- **自动化重复工作**：把提示词设为云端定时任务，在自己的流水线里用无头模式，并把 Claude 接入拉取请求做托管代码审查与 GitHub Action
- **验证与分享**：按你盯着的程度成比例地验证无人值守的运行结果，用钩子以真实测试结果把关，并把可信的配置打包成插件供全队安装
